# Afrikett (legacy)

Marketplace and social app: seller showcases, posts, stories and chat, in French.

This repository holds the native Android app (Java and Kotlin). It is archived and no longer maintained, and the app is no longer published.

## Project

- Application id: `com.neteru.afrikett`
- Version in this repository: 1.0
- Android Studio project (Gradle), `minSdkVersion` 16

The project targets the Android SDK and Gradle versions of its time and is not expected to build as is with current tools.
